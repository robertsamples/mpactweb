# Installation

## Web app

Use MPACT at **[app.mpactms.org](https://app.mpactms.org)**. There is nothing
to install: sign in with your email address and start with the
[Quick start](quick-start.md). This is the recommended way to use MPACT, and
the rest of this documentation describes it.

## Your own server

To keep data on your own computer, work offline, or host MPACT for a lab or a
class, run the same web app yourself. See
[Running your own server](../self-hosting/index.md).

## Standalone desktop app

!!! warning "The desktop app is no longer developed"
    Further development of the Qt-based desktop app has been discontinued in
    favour of the web version. Existing releases remain available, but new
    features and fixes go into the web app only.

A standalone Windows build of the desktop app is available from the
[releases page](https://github.com/robertsamples/mpact/releases). Download the
latest `MPACT_v*.zip`, extract it, and run `MPACT.exe`.

The desktop app runs the same analysis as the web app, and `.mpct` session files
open in either one, so you can move an analysis from the desktop app to the web
app with [Open session file...](../setup/file-selection.md#opening-a-session-file).
